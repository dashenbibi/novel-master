# 伏笔追踪表

## 使用说明

- **编号**: F001, F002, F003... 分配唯一编号，沿用项目现有编号方式
- **类型**: 物品/秘密/预言/人物/事件/其他
- **状态**: 计划中 / 埋下 / 推进中 / 已回收 / 已废弃；沿用现有项目的状态名称
- **首次出现**: 计划中的伏笔标“待埋”，正文实际出现后记录章节；不要把卷纲计划当作已发生事实
- **回收章节或方向**: 尚未确定时可标“待定”

## 伏笔类型说明

### 物品类

- 神秘道具、传家宝、信物等
- 例：主角佩戴的神秘玉佩

### 秘密类

- 角色身份、过往事件、隐藏真相
- 例：主角的真实身世

### 预言类

- 预言、诅咒、命运
- 例：古老的预言内容

### 人物类

- 神秘人物的真实身份
- 例：帮助主角的神秘人其实是 XX

### 事件类

- 将要发生的大事
- 例：即将到来的灾难

## 检查清单

每写完 10 章检查：

- [ ] 新增伏笔是否已记录
- [ ] 是否有伏笔可以回收
- [ ] 是否有伏笔需要调整

每写完 1 卷检查：

- [ ] 本卷伏笔回收情况
- [ ] 是否有遗漏的伏笔
- [ ] 下卷需要埋下的新伏笔
