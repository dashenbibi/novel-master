# 文风统一指南

## 建立文风样本

### 收集样本

优先遵循用户本次要求和项目文风文件；有冲突时以本次明确要求为准。项目没有文风文件时，可从作者认可的已有章节中按需选取少量相关片段作为参考，不要求凑齐类型或复制建档。样本仅辅助判断，不覆盖情节事实。

可参考的样本：

- 动作描写样本
- 情感描写样本
- 对话样本
- 环境描写样本

### 可选样本格式

```markdown
## 文风样本

### 动作描写

[复制精彩打斗片段]

### 情感描写

[复制情感爆发片段]

### 对话

[复制精彩对话片段]

### 环境描写

[复制场景描写片段]
```

## AI 味检查

以本书风格和实际语境为准，检查重复套话、机械句式、碎句、对话声线、场景详略及故事承接。准确的直接叙述、心理描写和有功能的修辞可以保留。完整检查与改稿边界见 [去 AI 味与润色指南](deep-polish-guide.md)。

## 一致性检查清单

每章完成后检查：

- [ ] 叙事视角是否一致
- [ ] 语言风格是否统一
- [ ] 角色对话是否符合性格
- [ ] 用词是否与前期一致
- [ ] 描写密度是否适合场景与本书风格
- [ ] 叙述口吻是否稳定
- [ ] 角色声线是否彼此区分
- [ ] 章末收束方式是否符合项目规则

## 修改建议

### 常见问题

1. **风格漂移**: 查阅作者认可的相关文风样本和项目规则
2. **对话雷同**: 结合人物身份、关系和当下意图区分表达，不强加口头禅
3. **描写过度**: 参考前文密度调整
4. **节奏失控**: 检查场景目的、详略和已有节奏安排
5. **AI 味过重**: 先定位重复解释、机械表达和承接缺口，保留有功能的写法

### 修改流程

1. 完成初稿
2. 有条件时稍作间隔，再回读
3. 重读并标记问题
4. 对照文风样本修改
5. 朗读检查流畅度
