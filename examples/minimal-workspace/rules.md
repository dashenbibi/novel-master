# 本书规则（九品仙奴）

## 1. 文风与节奏

- **基调**：冷峻、凶戾、铁血肃杀。强调泥水、血腥、斩马刀破空受力、骨肉撕裂手感与真实物理阻力，坚决杜绝悬浮空洞的玄幻修辞。
- **正文字数**：每章目标 2500–3200 字。
- **节奏把控**：
  - 肉搏与突发冲突：极短句为主，强化近身搏杀动作、重心转换、器械破甲与生理创痛，不写“法宝光华漫天”等虚浮套话。
  - 对峙与审讯：突出微动作、换气粗细、眼神落点、兵刃出鞘寸数与杀气压迫。
- **章末收束**：严禁用大道理总结、命运宣告或虚空拔高；每章末尾必须落在**具体危机临头、发现致命把柄、或反杀动作刚落下的物理节点**上。

## 2. 对话与心理描写纪律

- **对白原则**：南荒边陲恶宗，人命如草芥。
  - 台词必须服务于**威逼、索命、索贿、示弱装蠢或下套**，严禁向读者生硬科普设定。
  - 许良少言寡语，对上官回答极短，内心杀意越烈，面上神情越木然；崔道成言语带军汉匪气，字字带骨带刺。
- **潜台词**：上官说“宗门记你一功”，潜台词是“该准备寿材了”；说“下不为例”，潜台词是“把随身油水全交出来”。
- **心理描写**：拒绝抽象的“许良心中大惊/暗道不好”。情绪必须落在**生理反应**（如牙关咬破内唇渗血、掌心握紧镰柄皮肉泛白、重心微沉蓄力、呼吸压制如游丝）。

## 3. 工业级去 AI 味清单

- **绝对禁用词组**：
  - 严禁“深吸一口气 / 倒吸一口凉气 / 瞳孔猛地收缩 / 嘴角勾起一抹玩味的弧度”。
  - 严禁“不得不说 / 空气仿佛凝固了 / 宛如神魔降世 / 天地为之色变 / 宛如地狱爬出的恶鬼”。
  - 严禁“眼神中闪过一丝复杂/决绝/怨毒/欣慰之色”（换为具体眼皮抽搐、视线焦点移转或颈部青筋暴起）。
- **拒绝解说腔**：严禁出现“这就是修仙界的残酷法则”“正如前文所言”等说教性旁白。所有宗门残酷必须通过被践踏的药奴肉身、血肉模糊的斩骨刀、克扣碎灵的黑账自然暴露。

## 4. 称谓与专有术语

- **固定术语**：
  - 境界：炼气期（一至九层）、筑基期、金丹期。
  - 编制：九品仙奴（下三品为药奴/苦役，中三品为杂务/道童，上三品为战奴/随侍）、巡山执事、内门弟子、堂主长老。
  - 货币：下品灵石、碎灵、南荒血铁刀币。
  - 兵刃与道具：七尺斩马刀、阴铁割草镰、锁魂牌、断魂账。

## 5. 章节标准结构

所有章节统一采用以下三段式结构：

```md
# 第 X 章：[章节标题]

## 正文
（完整交付，不留任何占位符）

## 记忆更新清单
- 境界/战力/伤势状态
- 兵刃/血牌/残页道具转移
- 人际信任与杀机动向

## 本章备注
- 伏笔埋设/回收核验
- 下一章生死接口
```
