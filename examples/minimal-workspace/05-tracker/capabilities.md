# 能力边界与战力追踪看板（《九品仙奴》）

用于追踪白浮宗体系下的实力梯队、资源损耗与冲突破局因果，防止后期战力膨胀与逻辑失真。

## 1. 体系位阶与层级标准

| 层级 / 阶位 | 核心特质与表现标准 | 代表性常规能力 | 典型门槛与局限 |
| :--- | :--- | :--- | :--- |
| 杂役仙奴（丁字级） | 凡人至炼气初期（炼气一至三层），四灵根或杂灵根 | 辨药、劈柴、干重体力活，寿数不过甲子 | 无正统法门，经脉驳杂，受锁魂牌制约，随时沦为人药 |
| 巡山执役（丙/乙级） | 炼气四层至炼气九层（崔道成为炼气八层巅峰） | 七尺斩马重刃、气血如虎熊、百步疾驰纵跃 | 功法多残缺，暗伤累积严重，受制于内门管事克扣丹药 |
| 内门弟子（甲字级） | 炼气圆满至筑基期，掌握真传法术与正规法器 | 飞剑御物、护体罡气、神识外放数十丈 | 宗门资源倾轧严苛，晋级天堑需剥髓炼药维持地位 |
| 宗门巨头 / 管事（古不疑） | 筑基后期至金丹期 | 凌空御风、寿元数百年、一击崩碎山梁 | 高阶延寿药引难求，暗中圈养血牲，严防外门反噬 |

## 2. 核心角色能力与资源状态

### 主角：许良（丁七）

- **当前位阶 / 实力**：表面炼气三层，实为炼气四层初期（隐匿一层）
- **核心能力 / 专长**：药理毒理辨识（熟悉三十六种毒草相克）、近身割草镰快刀、微表情与生死距离直觉
- **隐藏底牌 / 专属机制**：草鞋夹层内的断魂账死签、贴肉缝合的古黑铁残片（杀机与神识物理刺痛示警，能吸噬药毒）
- **关键短板 / 代价限制**：仙奴锁魂牌被锁在巡山堂沉匣内、身份低微随时可能被灭口、经脉有草药暗蚀
- **关键装备与剩余储备**：浸透腐尸草汁的阴铁割草镰、半斤生石灰粉、三枚下品碎灵砂

### 核心敌手：黑刀崔（崔道成）

- **位阶与专长**：巡山哨所执事，炼气八层巅峰，修习残缺《血煞刀法》，行伍悍卒近战极强
- **核心装备 / 资源**：七尺黑铁斩马刀、生铁软甲、巡山血号角、麾下两条披铁甲的嗜血獒犬
- **限制与代价边界**：早年修炼残缺血煞功留下经脉暗伤，阴雨天气血逆冲，极度依赖人血丹药压制反噬

### 盟友：温巧娘（温秀）

- **位阶与专长**：百草谷药女，炼气三层中期，精通灵植催生、奇毒调配与气息掩匿
- **核心装备 / 资源**：青麻引雀粉、淬毒桃木骨针、特制辨药铜称
- **限制与代价边界**：幼弟受押在甲字药山充当药童，软肋被执事层死死拿捏

## 3. 越级破局与重大对决因果记录

| 发生章节 | 交锋双方 | 胜负结果 | 要素 1：信息差与弱点 | 要素 2：机制与克制手段 | 要素 3：借势与外部变量 | 要素 4：实际付出代价 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 第 1 章 | 许良 vs 崔道成 | 涉险过关（心理盘查） | 利用对方急于起获主册心理，提前撕下死签并草草糊泥掩盖魔煞爪印 | 以杂役顺从惊恐体态与残缺账本主动献交瓦解警惕 | 借暴雨夜药垄泥泞与药苗受损作为不在场掩护 | 自割左臂伪造护药伤痕，承受斩马刀压喉重创惊悸 |
| 第 15-17 章（规划） | 许良 vs 崔道成 | 逆风斩杀（断魂崖绝杀） | 摸透崔道成血煞功阴雨天经脉逆冲暗疾与视线盲区 | 生石灰呛瞎獒犬与双目，腐尸草阴铁镰见血溃烂克制硬功 | 断魂崖狭窄险隘绝阵，雷暴雨夜掩盖兵刃碰撞与声响 | 许良肋骨断折三根，割草镰崩损，杀敌后必须夺牌远遁内门 |

## 4. 战力防崩核查清单

每 10 章对照检查：

- [ ] 许良未通过正统机缘前，严禁凭空爆发修士级灵压
- [ ] 面对高阶修士对决，必须严格满足四要素（信息差、机制克制、借势外部、代价闭环）组合
- [ ] 碎灵砂、药散与伤药数量在各章之间必须保持数字闭环
- [ ] 崔道成等反派角色必须保持悍卒老手警惕与凶狠本色，严禁随意降智
